Trade Bridge

The Heikin Ashi Overlay can print TBSIG|BUY|SYMBOL|VOLUME markers on confirmed candles. The Chrome extension reads those markers and sends an order request to a local Python bridge that talks to MetaTrader 5 on your Windows machine.

  1. Install the Indie indicator from this vault and enable Emit TBSIG markers.
  2. Load the Chrome extension from extension-trade-bridge/.
  3. Run the local bridge from mt5-bridge/ with your MT5 terminal logged in.
  4. Set your bridge token and symbol allowlist in the extension popup.
Real money warning. Auto-execution stays off until you explicitly set TB_AUTO_TRADE=1, TB_DRY_RUN=0 and TB_ACKNOWLEDGE_REAL=1. Start in dry-run mode, verify the logs, then enable live trading. Trading Brain indicators are analysis drafts, not verified strategies and not financial advice.
